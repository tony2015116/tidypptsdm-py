    更新日志¶

    1.1.5¶

    桌面程序（exe）和它的定时任务；Python 函数、命令行和 R 版不变。

    • 报告改为中文，图也是中文（电脑上有中文字体时，例如微软雅黑；没有时图用英文）。
    • 报告首页先列出“今日待办”：需要检查的测定站、需要看的猪、长期未访问的猪，每条标出“新”或“持续 N 天”。
    • 少误报：
      • 测定站中途停止记录（如“从 07:50 起没有记录”）只报一条，不再给站上的每头猪各报一条；白天长时间没有记录也会提示；
      • 数据的最后一天在 22 点以前结束（白天导出）时，报告看前一天；
      • 超过 3 天没来的猪列为“长期未访问”，不再每天报严重；
      • 离场猪名单（结果文件夹里的 离场猪.txt）：名单上的猪不再报警。
    • 新警报“采食骤降”：一头猪的采食比它自己前几天的平均低 50% 以上（可设置，0 = 不检查）。测定站的采食下降改为比较头均采食，猪变少不会误报。
    • 运行信息的结论、状态栏和 Excel 的 Alerts 表与报告一致。
    • 趋势图和分小时图的纵坐标标题竖排，图更宽；分小时图的访问次数用整数刻度。
    • 趋势图、采食量图和体重图的横轴每天都标日期，竖排。

    1.1.4¶

    • 桌面程序和定时任务的运行信息改为中文：五个步骤各一行，带用时，作图时显示进度和进度条；最后是结论（最后一天的概况、严重警报逐条列出，最多 10 条，警告只给数量；数据过期的提示）。出错时说明原因和怎么办。命令行和 Python 函数的提示仍是英文，与 R 版一致。
    • 手动运行也写日志 tidypptsdm.log；日志超过 1 MB 时旧内容移到 tidypptsdm.log.1。
    • 文件里个别时间读不出时，只报告这几个值和原始列名（以前会把整列都报成读不出）。
    • 命令行 -q 不再输出开头的一行。

    1.1.3¶

    • 报告作图更快：6 台测定站以上时用电脑的多个核同时作图（最多 8 个进程），图和报告与一次画一台时完全相同。128 万行、80 台测定站的数据，在 2 核电脑上从 78 秒减到 42 秒；核越多越快。新参数 workers（命令行 --workers），1 为一次画一台。

    1.1.2¶

    • 桌面程序去掉时区选项：带时区标记的时间（如 2025-01-24T00:34:17Z）固定换算成北京时间，与电脑的时区设置无关。普通导出（如 2026/10/30 1:04）不受影响。
    • 采食量图：按耳标号的实际长度留出图例的位置，15 位电子耳标号也不再与图重叠。
    • 去掉热图（type="heatmap"）：天数多时看不清；每头猪的采食情况看采食量堆叠图和猪只表。

    1.1.1¶

    • 读取 ISO 8601 格式的时间，如 2025-01-24T00:34:17Z、2025-01-24T08:34:17+08:00。带时区的时间换算后再按天统计，Python 和命令行用参数 time_zone（--time-zone）设置。没有时区标记的普通导出不受影响。
    • 桌面程序：先加载自带的 Tcl/Tk，避免其他软件的 Tk 干扰；窗口打不开时给出中文说明和诊断文件；新命令 tidypptsdm selftest。
    • 测定站很多时，报告逐站作图并显示进度，内存占用更小。
    • 定时任务：用电池时也运行，错过的运行在开机后补跑；直接启动程序（不弹窗口，中文路径也没有问题）；每次运行在日志里记下开始时间。新增 tidypptsdm status，桌面程序新增“查看定时状态”“立即运行一次”。
    • 数据的最后一天离今天超过 1 天时，运行信息和报告首页提示“最新数据是 N 天前的”。桌面程序新增“截止日期”，用于回看历史。

    1.1.0¶

    第一个 Python 版本，对应 R 包 tidypptsdm 1.1.0。

    • 读取 NEDAP 和 FIRE 导出文件（CSV、TXT、Excel），格式文件与 tidypptsda 通用；整理规则与 tidypptsda::prep_visits() 相同（未识别访问、跨午夜、转栏与误读）。
    • run_monitor()：每站、每栋、每猪、每小时的日表和最后一天的警报；与 R 版逐表一致。
    • 图：趋势（含体重）、采食量堆叠柱状图、热图、体重箱线图、分小时图。
    • HTML 报告（与 R 版页面相同）、Excel 工作簿（带色阶）或 CSV。
    • 每天定时运行：Windows 任务计划程序或 crontab。
    • 命令行 tidypptsdm 和桌面程序（Windows exe，不需要安装 Python）。
